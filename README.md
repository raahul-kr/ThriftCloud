# ThriftCloud 🌩️🪂

![ThriftCloud Architecture](https://via.placeholder.com/800x200?text=ThriftCloud+Architecture)

ThriftCloud is a production-ready, multi-cloud cost intelligence platform for AWS and Azure. It analyzes your cloud billing data, detects wasted spending, and provides actionable recommendations to optimize your cloud efficiency.

## Overview

ThriftCloud allows you to:
- 🚀 Assess cloud costs across **AWS** and **Azure**.
- 📊 **Upload your own billing files** (CSV, TXT, JSON).
- 💡 Get **Efficiency Scores**, **Savings Potential**, and **Actionable Recommendations**.
- 🛡️ Run the application locally with Docker Compose or deploy seamlessly to an AWS EC2 free-tier static IP instance.

## 🚀 Running Locally

ThriftCloud is fully containerized and easy to run locally.

### Option 1: One-Command Start (Windows PowerShell)

We've included a script that installs dependencies and runs both the Frontend (Port 3000) and Backend (Port 8000) side-by-side.

```powershell
.\scripts\run_local.ps1 -InstallDeps
```

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:8000/api/health`

### Option 2: Docker Compose

If you have Docker installed, simply run:

```bash
docker compose up -d --build
```
- Frontend will be exposed at `http://localhost:3000`.
- Backend will run on `http://localhost:8000`.

## 📖 API Reference

ThriftCloud exposes two main endpoints for cost analysis.

### `POST /api/analyze`
Analyzes billing data based on a predefined sample or custom inline JSON.

**Request (`application/json`):**
```json
{
  "provider": "aws",
  "billing_data": {
    "Amazon EC2": 1500,
    "Amazon S3": 500
  }
}
```
*(Note: `billing_data` is optional. If omitted, built-in sample data will be used).*

**Response:**
```json
{
  "total_cost": 2000.0,
  "savings_potential": 270.0,
  "efficiency_score": 83,
  "recommendations": [
    "Consider Reserved Instances or Savings Plans for EC2 to reduce compute costs by up to 40%.",
    "Move infrequently accessed objects to S3 Glacier or Intelligent-Tiering to cut storage costs."
  ],
  "breakdown": [
    {
      "name": "Amazon EC2",
      "cost": 1500.0,
      "category": "Compute",
      "recommendation": "Consider Reserved Instances or Savings Plans for EC2 to reduce compute costs by up to 40%."
    }
  ],
  "input_source": "request_payload"
}
```

### `POST /api/analyze/upload`
Analyzes an uploaded `.csv`, `.txt`, or `.json` billing file.

**Request (`multipart/form-data`):**
- `provider`: `aws` or `azure`
- `file`: The billing file.

Supported file formats:
- **CSV / TXT**: Must include `service` and `cost` header columns.
- **JSON**: Object `{"billing_data": {"EC2": 1300}}` or Array `[{"service": "EC2", "cost": 1300}]`.

## 🛠️ Deploy to AWS (Terraform)

You can deploy the stack to a Free Tier AWS EC2 Instance with a Static IP using the provided Terraform scripts.

### Deploy Steps:

1. Configure your AWS credentials:
```powershell
aws configure
```

2. Run the deployment script (it auto-detects your IP for SSH access):
```powershell
.\infra\aws_free_tier_static_ip\deploy.ps1 -Region "ap-south-1" -KeyPairName "thriftcloud-key"
```

_Note: If your public IP cannot be auto-detected, explicitly pass it:_
```powershell
.\infra\aws_free_tier_static_ip\deploy.ps1 -Region "ap-south-1" -KeyPairName "thriftcloud-key" -AllowedSshCidr "<your-public-ip>/32"
```

3. Post-Deployment
Terraform will output:
- `static_public_ip`
- `app_url`
- `ssh_command`

### Free-Tier Notes for AWS
- The default setup uses `t3.micro` which is eligible for the free tier depending on the region and account creation date.
- AWS charges for public IPv4 addresses, including Elastic IP. The free tier covers up to 750 hours of public IPv4 usage per month for the first 12 months.

## 🏗️ CI/CD Deployment (GitHub Actions)

ThriftCloud includes a GitHub Actions pipeline `.github/workflows/deploy.yml` which deploys code to EC2 upon a push to the `main` branch.

### Secrets Setup:
To enable the continuous deployment, add the following secrets to your GitHub Repository (**Settings → Secrets and variables → Actions**):

- `DOCKER_USERNAME`: Your Docker Hub username.
- `DOCKER_PASSWORD`: Your Docker Hub personal access token or password.
- `EC2_HOST`: The Static Public IP generated by Terraform.
- `EC2_KEY`: The raw private key (PEM content) of your AWS EC2 key pair.
